# Minimalist Redesign — Anthropic/Dario Amodei Aesthetic

## Visual Foundation
- Background: Warm cream/beige (#f5f0e8)
- Typography: Serif headings (Georgia), clean sans-serif body
- Dark charcoal text on cream, underlined links
- No dot matrix, gradients, colored tags, accent bars
- Single subtle page fade-in retained

## Homepage (Dario-style)
- Bold "James Hawley" heading
- Short bio with Resume/LinkedIn links
- Categorized sections: Essays, Tech, Economics, Books, Projects
- Bulleted links to actual posts
- Simple footer with email

## Navigation
- Name on left (home link), About/Writing on right
- Cream background, no dark bar
- Mobile: simple stacked links

## Blog Posts
- Centered narrow column (~680px)
- Large serif title, italic subtitle, date
- No scroll progress bar, no sticky back button
- Simple "back" text link

## About Page
- Clean prose, Resume/LinkedIn as inline links

## Category/Writing Pages
- Simple heading + description
- Text links with dates (no cards)

## Removed
- Dot matrix, gradient text, colored tags, card hover effects
- Scroll progress bar, sticky back button, dark nav bar
- Orange accent, hamburger animation complexity
